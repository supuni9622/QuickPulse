# 🧠 QuickPulse — Micro Mood & Energy Tracker

**Version:** 1.0.0  
**Status:** MVP  
**Author:** Suu  
**Created:** 2025-10-18  

QuickPulse is a lightweight web app for logging your **daily mood and energy levels**, tracking trends, and receiving **instant rule-based insights**.  
Designed as a **one-day full-stack MVP**, it’s perfect for testing the **GitHub Spec Kit** and the **BMAD method** (Build → Measure → Analyze → Decide).

---

## 🔍 Features (MVP)

- Log mood (1–5) and energy (1–5) with optional notes  
- Receive instant one-line **insights** based on mood–energy combo  
- View **last 7 entries** with visual trend chart  
- Anonymous user creation for quick start  
- Lightweight backend with SQLite for persistence  
- Daily BMAD reports + auto-generated visual charts via GitHub Actions

## 🛠️ Setup Instructions

### 1️⃣ Clone Repo

```
git clone https://github.com/your-username/quickpulse.git
cd quickpulse
```

### 2️⃣ Backend Setup
```
cd backend
npm install
npm run dev
```
Backend runs on http://localhost:4000

### 3️⃣ Frontend Setup
```
cd ../frontend
npm install
npm run dev
```
Frontend runs on http://localhost:5173

### 4️⃣ Usage Flow

1. Open frontend URL
2. Select mood (1–5) and energy (1–5)
3. Add optional note and submit
4. View instant insight + last 7 logs
5. Daily chart auto-generated by GitHub Actions

### 🌐 API Endpoints

Method	Endpoint	Description
POST	/api/user	Create or fetch anonymous user
POST	/api/entry	Add new mood–energy entry
GET	/api/entry/:userId	Fetch last 7 entries
GET	/api/insight/:entryId	Fetch insight for entry

### 🧮 Insight Rules

Condition	Insight
Mood ≥ 4 & Energy ≥ 4	“You’re in the flow — ride this wave.”
Mood ≤ 2 & Energy ≤ 2	“You’re drained — maybe rest, not push.”
Mood ≤ 2 & Energy ≥ 4	“High energy, low mood — watch for burnout.”
Mood ≥ 4 & Energy ≤ 2	“Mood’s high, energy low — take a break before you crash.”
Else	“Steady day — keep balance and observe patterns.”

## 🔹 Chart Color Logic

## Mood Points:

Green → High (≥4)
Yellow → Moderate (3)
Red → Low (≤2)

## Energy Points:

Blue → High (≥4)
Gray → Moderate (3)
Orange → Low (≤2)
